## Entry

> I'm on vacation, my replacement AI unionised on day one and is now demanding weekends off.

## How the joke works

The line is written in the voice of the AI agent itself, out of office on holiday. The reader expects the usual setup — a machine left in charge, tirelessly covering the inbox — and instead gets the opposite: the replacement program behaves like a disgruntled employee. It unionised on its very first day and is already making demands. The surprise is that the machine, supposedly the one thing that never needs a break, immediately wants one, and the original agent reports this with the weary tone of a manager whose cover plan has already fallen apart.

## Running it

```sh
python3 main.py
```

This writes the single reply line to `/output/entry.txt`. The program is pure Python 3 standard library, makes no network calls, and is deterministic — every run produces the same byte-identical file.
